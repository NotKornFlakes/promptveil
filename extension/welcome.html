How it works

  1. 1
    Paste into an AI chat as usual

    On ChatGPT, Claude, Gemini, Copilot, Perplexity, DeepSeek, Mistral and Grok, PromptVeil swaps emails, phone numbers, keys, passwords, card numbers and IP addresses for placeholders like [EMAIL_1] before the site ever sees your paste.

  2. 2
    Ask the AI

    Its answer uses the same placeholders. The same value always gets the same placeholder, so the AI can still tell who's who.

  3. 3
    Copy the answer with the real values back

    Click Copy with real values under the answer, or select text and press Ctrl+Shift+Y (or right-click → Restore real values with PromptVeil). The restored text goes to your clipboard, never into the AI's page.

Good to know

  • Your own words. PromptVeil doesn't recognize names or company names by itself. Add them under Settings → Always hide in the PromptVeil menu.
  • Typed text. Only pasted text is scrubbed automatically. Turn on Check typed text before sending in Settings to also catch what you type.
  • Memory only. The placeholder mapping is kept in memory and erased when you close the browser.
  • Pin it. Click the puzzle-piece icon in the toolbar and pin PromptVeil to reach it quickly.
